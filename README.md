# Sentiment Analyzer

This is a small Python project I created to practice basic NLP and sentiment analysis.

The program takes text from the user and checks whether the sentiment is positive, negative, or neutral.

## Technologies
- Python
- TextBlob

## Run

pip install -r requirements.txt

Run the program:

python sentiment_analyzer.py

## Example

Enter a sentence: I really enjoyed learning Python.

Sentiment: Positive  
Polarity Score: 0.5
